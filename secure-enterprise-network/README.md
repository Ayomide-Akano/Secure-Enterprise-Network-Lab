# Secure Enterprise Network Lab

This repository documents and supports a secure enterprise network architecture for a Headquarters (HQ) and a Branch office.

## Repository structure

- `docs/` – design, addressing, and security documentation
- `diagrams/` – network topologies and architecture diagrams
- `configs/` – HQ and branch configuration files
- `packet-tracer/` – Cisco Packet Tracer project file and related assets
- `testing/` – validation and test results

## Overview

This lab focuses on:
- secure enterprise WAN connectivity
- segmentation and access control
- routing and switching design
- firewall and remote access controls
- HQ and branch office connectivity patterns
